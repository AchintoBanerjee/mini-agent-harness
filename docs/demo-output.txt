$ java --enable-native-access=ALL-UNNAMED -cp "target/classes:target/lib/*" harness.cli.Main serve --port 0
listening on http://localhost:58348 · agents/ tools/ harness.db · POST /runs queues a turn for a worker · ctrl-c stops it
(the server stays in the background; --port 0 picked a free port, the manual uses 8080)
$ java --enable-native-access=ALL-UNNAMED -cp "target/classes:target/lib/*" harness.cli.Main worker --api http://localhost:58348

(the worker stays in the background too: the server only queues turns, this process runs them and pushes every event of a turn to the server, which holds the run's stream)
